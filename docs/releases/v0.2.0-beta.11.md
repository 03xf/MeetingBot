# v0.2.0-beta.11 · 托盘交互与 MiMo 兼容修复（Windows）

修正“隐藏到托盘后再打开，字幕还在变化但无法点击”的 Windows 窗口路径，更新已经下线的 MiMo 模型配置。本版为测试预发布版。

## 下载和升级

- 安装版：`MeetingBot-0.2.0-beta.11-win-x64.exe`
- 免安装版：`MeetingBot-0.2.0-beta.11-win-x64-portable.exe`
- 两个 EXE 均附 SHA256；另附 `MeetingBot-focus-check.html`。
- 先从托盘完全退出旧版，再运行新版；设置中的版本应为 `0.2.0-beta.11`。配置、知识库、会话仍保存在原来的 `%APPDATA%\MeetingCopilot`。

## 托盘恢复后无法点击

用户进一步确认：卡住时字幕仍在变化，托盘“恢复界面”可以恢复。这与界面进程完全停止不同，重点是不可聚焦窗口隐藏再显示后的鼠标交互。

Windows 主窗口现在保持原生窗口已显示状态：隐藏时设为完全透明并开启鼠标穿透；唤醒时恢复原生不透明度和鼠标接收。托盘和快捷键使用独立的逻辑可见状态，不再依赖原生 `isVisible()` 判断是否隐藏。浏览模式继续不可聚焦；主动进入编辑模式仍允许聚焦。标题栏“—”使用同一路径，禁用主窗口原生最小化入口，避免重新进入该过渡。

这只改变 Windows 主窗口的隐藏方式。显示时原生不透明度恢复为 1，原来的背景透明度设置仍通过 CSS 生效，文字和代码不会随背景变淡。隐藏期间录音和回答继续运行；无需为每次隐藏重启界面。已有托盘恢复入口保留。

## MiMo 模型下线与连接提示

[小米官方下线公告](https://mimo.mi.com/docs/zh-CN/updates/deprecate)明确：`mimo-v2.5` 和 `mimo-v2.5-pro` 已于北京时间 **2026-10-21 10:00** 下线，无自动替换模型。旧版本截图预设仍使用 `mimo-v2.5`，因此已过期。

- 新预设：截图模型 `mimo-v2.6-flash`，MiMo 文本模型 `mimo-v2.6-pro`。
- 启动时仅迁移 `https://api.xiaomimimo.com/v1` 上的上述两个旧模型名；保留加密 Key，清除过期连接测试结果，并显示迁移提示。其他服务商、自定义中转地址和 `mimo-v2.5-asr` 不变。
- 新模型按其当前价格计费，请在设置中重新测试连接；本次回归没有使用用户 Key 调用真实计费模型，不能代替账号权限、余额验收。
- 官方 MiMo 文本 / 视觉请求使用 `max_completion_tokens` 并关闭思考，限制交互回答输出量，避免默认大输出与长思考影响等待时间。参考[官方接口](https://mimo.mi.com/docs/en-US/api/chat)。其他服务商参数保留。
- HTTP 410 和模型下线标识归为“模型不可用、已下线或模型名已变化”；常见连接重置错误归为网络错误。高级详情增加 HTTP 状态和安全的传输错误码，不显示原始响应、截图或 Key。
- 视觉请求主动取消会结束等待，增加 90 秒上限及中途断开处理，避免取消后仍悬挂；连接测试仍使用原来的 12 秒预算。修正中文字符跨响应块时的解码。

## 验证与限制

- 类型检查、447 项 TypeScript 测试、8 项 Python 测试、构建及两条 ASR worker 模拟链路。
- 隔离配置中完成 20 次托盘隐藏 / 唤醒、隐藏 65 秒后唤醒：没有原生 hide、没有浏览窗口 focus 事件；唤醒后 Chromium 鼠标事件能打开会话菜单。验证 MiMo 配置迁移和界面提示、截图取消、界面恢复、录音 / 生成停止和保存会话恢复。
- 实际 Electron 网络栈与本地 HTTP 服务验证视觉请求、中文分块、HTTP 410、取消及响应中断；自定义提示词和背景透明度回归。发布流程另检查打包后启动与 SHA256。
- **按用户要求跳过真实鼠标验收**。程序化鼠标事件不等于原生 Windows 命中测试；原故障仍需用户本机使用反馈。Edge / Chrome 可见性和真实平台兼容性本轮未实测；飞书、北森、京东、腾讯及飞书桌面客户端均不得据此标为通过。
- 采集保护与浏览模式的含义不变；本版没有承诺隐藏所有平台的检测事件。
