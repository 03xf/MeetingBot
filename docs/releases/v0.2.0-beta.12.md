# v0.2.0-beta.12 · 浏览锁定与无焦点交互测试版（Windows）

浏览模式不再因误点设置、导入或文字编辑入口而自动变成可聚焦窗口。本版为测试预发布版；不承诺所有测评平台都不会报警。

## 下载与使用

- 安装版：`MeetingBot-0.2.0-beta.12-win-x64.exe`
- 免安装版：`MeetingBot-0.2.0-beta.12-win-x64-portable.exe`
- 两个 EXE 各附 SHA256，另附离线 `MeetingBot-focus-check.html`。
- 先从托盘完全退出旧版，再运行新版；设置中应显示 `0.2.0-beta.12`。原有配置、知识库、自定义提示词和会话沿用 `%APPDATA%\MeetingCopilot`，无需数据迁移。
- 每次启动默认 **浏览·锁定**。录音启停、隐藏 / 唤醒、确认回答、停止生成、滚动、复制、会话切换和截图继续使用现有不可聚焦窗口路径。
- 设置、导入、重命名、输入、配置向导、外部链接和数据文件夹在浏览模式只显示：**“请手动切换到编辑模式，此操作会使测评页失焦。”** 托盘不能绕过锁定。
- 只有标题栏模式按钮允许主动进入编辑。设置保存 / 取消、导入完成 / 取消、结束重命名和关闭向导后自动恢复浏览；不会主动激活别的程序，请自行返回测评页后再使用。编辑状态不跨启动保存。
- 首次授权和设备配置请提前完成；使用期间录音错误在界面内提示，不自动打开设置。

## 实现与保留功能

Windows 主进程统一检查会打开窗口、文件选择器或外部程序的入口；新增 `window:interaction-blocked` 通知，携带操作标识。被阻止的文件选择返回取消、知识库导入返回当前摘要，外部链接 / 文件夹 / 向导返回失败，不打开相应窗口。

沿用托盘隐藏、剪贴板接口、页面内会话菜单和原有浏览 / 编辑模式，没有引入新的桌面图层。截图层保持不可聚焦及原生透明属性；完成、取消按钮、右键、重复快捷键、超时及异常清理均沿用不激活主窗口的路径。录音截断、知识库、提示词、透明度和 beta.11 的 MiMo 配置兼容修复保留。

**采集保护**是窗口被屏幕采集时的保护设置；**浏览模式**控制窗口是否允许获得输入焦点。两者都不能保证平台无法通过其他规则检测到辅助软件，也不能替代平台兼容测试。

## 验证结果与未验证项

- 类型检查、448 项 TypeScript 测试、8 项 Python 测试、构建及两条真实 ASR worker / 本地模拟服务链路通过。
- 隔离 Electron 配置中回归浏览入口误触、直接 IPC、托盘设置 / 更新入口；被阻止时没有文件选择器、外部程序或配置向导副作用。设置保存 / 取消、文件取消 / 实际测试文档导入、重命名结束和向导关闭后恢复浏览。
- 程序化窗口回归覆盖 20 次隐藏 / 唤醒和隐藏 65 秒后唤醒；浏览阶段没有窗口 focus 或原生 hide 事件。Chromium 程序化输入可以打开页面内会话菜单；录音错误、生成取消和界面恢复路径继续通过。
- 截图回归覆盖显示、有效 / 过小选区、取消按钮、右键、重复请求、重复快捷键、捕获失败及界面进程异常；单元测试覆盖捕获 / 选区超时与过期回调。此处是程序化回归，不是原生鼠标验收。
- 自定义提示词、透明度、视觉请求和取消回归，以及 Windows 打包启动检查通过；发布时核对 SHA256。
- **独立 Edge：未通过验收校准。** 自动化打开对照标签页后，原页仍报告 `hasFocus() = true`、`visible`，没有应出现的失焦 / 隐藏；全屏正向校准也没有产生有效事件。这组数据被排除，不能把零事件称为浏览器兼容通过。
- **独立 Chrome：未实测。** 当前环境缺少可用的 Chrome 自动化连接。未以同进程 Chromium 对照替代独立浏览器验收。
- **真实鼠标命中与操作：按用户要求跳过。** 不宣称已完成原生点击、拖拽和快捷键验收；仍需本机验证实际可点击性、焦点、页面隐藏及全屏表现。
- **飞书网页版、北森、京东、腾讯及其他招聘平台：未实测。飞书桌面客户端：未实测。** 没有使用正式面试页面测试，也没有用本地页通过替代平台验证。

离线自检页新增退出全屏计数，并明确要求先主动切换窗口 / 标签页、退出全屏做正向校准，再重置逐项测试。若校准本身无效，或某操作产生失焦、隐藏、退出全屏，应记录该操作与事件，不将其标为通过。
