# v0.2.0-beta.13 · 自定义截断回答快捷键（Windows）

设置中仅新增 **“截到此刻并回答快捷键”**。默认留空，不预设组合键，请自行设置；留空即禁用。

## 下载与设置

- 安装版：`MeetingBot-0.2.0-beta.13-win-x64.exe`
- 免安装版：`MeetingBot-0.2.0-beta.13-win-x64-portable.exe`
- 两个 EXE 各附 SHA256，另附 `MeetingBot-focus-check.html`。
- 从托盘完全退出旧版再安装新版；原配置、知识库、提示词、会话及原有显示 / 隐藏、截图快捷键保留。
- 从标题栏主动切到编辑，再打开设置，填写“截到此刻并回答快捷键”并保存；保存后自动回到浏览模式。组合键采用 Electron 格式，例如 `Control+Shift+F9`，这是格式示例，不会自动绑定。
- 快捷键在窗口隐藏时也有效，不会自动显示或激活窗口。被其他程序占用、与本程序其他快捷键重复或格式无效时，界面显示注册失败提示；修改保存后重新注册。

## 行为

按自选快捷键复用确认按钮的音频截断、识别及合并提交路径。没有待提交内容且未录音、已有回答在生成或正在截断时不会重复提交。正在整理截断内容时重复触发快捷键，不会取消该次提交。要取消仍使用原有按钮。

新增快捷键只派发截断回答操作，不调用显示、聚焦或编辑模式入口。设置保存后即时更新，重启后保留。每个快捷键独立注册，一个无效或被占用的组合键不会阻断后续快捷键注册。浏览锁定、截图、录音和原有按钮行为沿用 beta.12。

## 验证与限制

- 类型检查、451 项 TypeScript 测试、8 项 Python 测试、构建及两条 ASR worker / 本地模拟服务链路通过。
- 隔离配置验证实际设置输入框保存自选组合键、重启后回显；旧配置新增字段默认为空，已有选择与禁用配置保留。
- 程序化 Electron 回归验证窗口隐藏时截断回答、重复回调只提交一次、取消按钮与迟到识别结果的交互、修改绑定、禁用及注册失败提示。浏览阶段没有窗口 focus 事件，快捷键操作未显示隐藏窗口。
- 原有浏览锁定、截图生命周期、恢复界面、自定义提示词、透明度和视觉请求回归通过；Windows 发布流程验证打包启动并核对 SHA256。
- 本轮使用程序化快捷键回调与隔离本地服务，没有把回调测试等同于 Windows 原生按键或鼠标验收。具体组合键能否被操作系统注册，仍以你本机界面提示和使用结果为准。
- 独立浏览器及真实平台没有新增验收结论。beta.12 的 Edge 自动化正向校准无效、Chrome 自动化不可用；飞书、北森、京东、腾讯及飞书桌面客户端继续标注未实测。不能据此承诺所有平台都检测不到。
