# v0.2.0-beta.15 · 鼠标截图提问按钮（Windows）

顶部工具栏新增 **“📷 截图提问”** 按钮，直接用鼠标操作截图问答，无需按截图快捷键。

## 下载与使用

- 安装版：`MeetingBot-0.2.0-beta.15-win-x64.exe`
- 免安装版：`MeetingBot-0.2.0-beta.15-win-x64-portable.exe`
- 两个 EXE 各附 SHA256，另附离线焦点自检页。
- 从托盘完全退出旧版后更新。配置、知识库、会话、提示词、透明度、录音区间与原有快捷键继续保留。
- 点击顶部“截图提问”，拖动框选屏幕区域；完成后自动交给视觉模型识别并回答。右键、取消按钮或原截图快捷键仍可取消框选，取消不提交。
- 纯文本回答模式下也能单独使用此按钮，截图不会切换后续语音回答的模型模式。
- 如未配置视觉模型，只显示界面内提示。请自行从标题栏进入编辑模式，在设置中填写视觉模型的 Base URL、模型和 API Key；不会自动打开设置或向导。

## 验证与范围

- 类型检查、453 项 TypeScript 测试、8 项 Python 测试、构建及四条 ASR worker 模拟链路通过。
- Electron 隔离配置通过 Chromium 鼠标事件点击实际按钮，验证框选取消不请求模型、有效选区携带图片发出真实本地 HTTP 请求并显示回答、纯文本模式保留，以及缺少视觉配置时不截图、不打开设置、只显示提示。
- 程序化浏览阶段没有窗口 focus 事件；检查工具栏在 640 和 940 CSS 像素窗口宽度下按钮均处于可见范围。
- 录音区间、知识库、提示词、透明度、截图清理、界面恢复和视觉传输回归继续通过。Windows 发布流程验证打包启动并核对 SHA256。
- 本次使用合成截图、本地模拟服务和程序化鼠标事件，没有使用真实桌面截图、用户 Key 或计费服务；不等同于原生 Windows 鼠标命中或独立浏览器验收。
- 按钮复用现有不可聚焦截图路径，不发送模拟键盘事件。第三方测评网站对鼠标、焦点、页面隐藏或其他行为的规则仍需分别验证；不保证所有平台都不报警。
