# v0.2.0-beta.16 · 鼠标截取区间，中文界面与仅系统声音（Windows）

主界面新增 **“开始截取”** 按钮，第一次点击标记起点，第二次点击 **“结束截取并回答”**。只将两次点击之间的音频作为本轮问题，与已配置的 Right 快捷键共用同一状态。

## 使用变化

- 先点击“开始”并等待采集就绪，再点击“开始截取”。识别完成后回答，设备保持采集，后续可继续选择下一段。
- 不设置任何区间快捷键也能用按钮；可以按钮开始、快捷键结束，或反过来。正在整理或生成时不能重复开始，避免重复提交。
- 原“截到此刻并回答”仍可用于合并全部待确认问题；已进入区间时，它也会结束该区间。停止采集、切换会话、清空转写会取消未提交的区间。
- 删除主界面的中英回答切换和麦克风按钮；设置、配置向导也移除语言切换和自身麦克风的启用 / 设备选择入口。
- 界面与默认回答提示固定为中文，语音识别仍能识别中英混合内容。
- 不打开自身麦克风，只采集会议 / 系统输出音频。旧配置中的 `micEnabled=true` 和英文偏好会重置；模型、Key、个人知识库、提示词、透明度、会话和快捷键保留。
- 系统回环采集按音频来源区分，不进行说话人身份识别；已被回放进系统输出的声音仍属于这一路音频。
