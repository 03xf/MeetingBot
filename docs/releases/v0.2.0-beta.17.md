# v0.2.0-beta.17 · 左右栏宽度可拖动调整（Windows）

转写区与回答区不再固定等宽。拖动中间的分隔线即可调整，松手后自动保存，重启或恢复界面后继续使用该比例。

## 使用

- 鼠标放在两栏中间的竖线，左右拖动。可以让转写区更窄，给回答与代码留更多空间。
- 双击分隔线恢复等宽；分隔线获得键盘焦点后也可用左右方向键微调，Shift 加速，Home / End 调到当前允许的边界。
- 两侧保留最小宽度；缩小窗口时临时限制实际宽度，放大后恢复偏好的比例。
- 拖动期间只预览，松手后才保存；取消拖动、失去指针捕获或页面隐藏时回到拖动前的比例。
- 浏览锁定模式可直接拖动，不要求切到编辑，不主动激活窗口。窗口内统一处理移动和松手，避免在边界处松手后卡在拖动状态。
- 继续保留区间截取、截图、知识库、提示词、透明度；中英和自身麦克风按钮保持移除，仅采集对方系统声音。

## 下载

- 安装版：`MeetingBot-0.2.0-beta.17-win-x64.exe`
- 免安装版：`MeetingBot-0.2.0-beta.17-win-x64-portable.exe`
- 两个 EXE 分别附 SHA256，另附离线焦点自检页。请先从托盘完全退出旧版再更新。

- 类型检查、458 项 TypeScript 测试、8 项 Python 测试、构建和四条 ASR worker 合成音频链路通过。
- Chromium 指针事件验证实际分隔线拖动、宽度上限处在内容区松手、取消恢复、双击重置、松手保存、缩窗约束、恢复界面后还原比例。浏览过程中未新增窗口 focus 事件或原生聚焦属性写入。
- 设置比例的默认值、异常输入、上下限与持久化回归通过；旧配置无需迁移即可使用。
- 区间、提示词、截图、浏览锁定、视觉传输与打包启动继续回归。仅使用隔离配置、合成音频 / 截图和本地服务。
