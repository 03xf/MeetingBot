# v0.2.0-beta.2 · 个人知识库增强版

基于 JWM0203/MeetingCopilot，新增个人知识库功能。适用于 Windows 10 / 11 x64。

## 下载

- **常规安装使用**：下载 `MeetingCopilot-0.2.0-beta.2-win-x64.exe`。
- **免安装使用**：下载 `MeetingCopilot-0.2.0-beta.2-win-x64-portable.exe`。
- 同名 `.sha256` 文件用于核对下载完整性；`Source code` 是源码，不是安装包。

先退出正在运行的旧版，再安装或启动新版。安装后在右侧回答区顶部点击 **📚个人知识库**，导入资料即可使用。模型服务仍需你自己的 API Key；云端方案无需安装 Node.js 或 Python。

## 新增功能

- 多文档导入：MD、TXT、DOCX、文字版 PDF；资料跨会话共用。
- 回答优先依据知识库，未覆盖的部分才补充通用知识；不将岗位要求当成个人经历。
- 可在本机预览检索结果，回答可展开查看参考原文。
- 手动回答、持续回答、自由提问和截图问答都接入知识库。
- 保留独立的简历/JD 功能，兼容迁移旧版全局资料。

## 验证与使用边界

- 发布流程执行类型检查、376 项 TypeScript 测试、8 项 Python 测试、构建、依赖补丁检查及打包后启动测试。
- 当前使用本地关键词检索，同义表达可能漏检；回答仍需自行核对，模型约束不等于事实校验。
- 资料本地保存；生成回答时，检索选中的参考段落会发送给你配置的模型服务。
- 本 Beta 安装包尚未做代码签名，Windows SmartScreen 可能显示提示。
