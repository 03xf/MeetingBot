# v0.2.0-beta.3 · 回答排版与代码框

修复回答直接显示 Markdown 源码的问题，保留上一版本的个人知识库功能。适用于 Windows 10 / 11 x64。

## 下载

- **安装版（推荐）**：`MeetingCopilot-0.2.0-beta.3-win-x64.exe`
- **免安装版**：`MeetingCopilot-0.2.0-beta.3-win-x64-portable.exe`
- 同名 `.sha256` 文件用于校验下载完整性。

先退出旧版，再安装或启动新版。已经保存的历史回答也会自动按新样式显示，无需重新提问。

## 本次修复

- 标题、加粗、列表、行内代码和表格正常排版，完整的 Markdown 标记不再直接显示。
- Java、Python、JavaScript、TypeScript、C/C++ 等代码放在独立代码框内，支持语法高亮和行号。
- 保留代码缩进、换行和空行；长代码行横向滚动，不强制折行。
- 每个代码块有独立复制按钮，复制内容不包含行号和排版标记。
- 支持流式生成期间尚未闭合的代码块，以及深色/浅色主题和窄窗口。
- 调整模型输出规则，要求代码使用带语言标记的围栏代码块。

## 验证与说明

- 类型检查、392 项 TypeScript 测试、8 项 Python 测试及构建通过；GitHub 发布流程还会运行打包后启动测试。
- 已使用隔离数据目录和本地模拟模型验证流式显示、历史回答、Java 高亮、行号、缩进、复制与复制失败反馈、主题和横向滚动。
- 展示层保留原始代码，不自动改写或修正模型生成的代码。未标注或不支持的语言仍显示为普通代码框。
- 本 Beta 安装包未做代码签名，Windows SmartScreen 可能显示提示。
