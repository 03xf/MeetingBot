# v0.2.0-beta.4 · 自动归并问题，手动确认回答

对方停顿造成的多段转写会持续累积，等问题说完再由你确认回答。保留个人知识库优先作答、Markdown 排版和代码高亮功能。适用于 Windows 10 / 11 x64。

## 下载

- **安装版（推荐）**：`MeetingCopilot-0.2.0-beta.4-win-x64.exe`
- **免安装版**：`MeetingCopilot-0.2.0-beta.4-win-x64-portable.exe`
- 同名 `.sha256` 文件用于校验下载完整性。

先完全退出旧版，再安装或启动新版。升级保留已有配置、个人知识库和历史记录；旧版本历史转录不会自动重新排队，从升级后新收到的语句开始收集。

## 使用方法

1. 点击 **▶ 开始**，一直收取对方录音。
2. 对方即使停顿、多次补充，语句都会累积在左侧 **待确认问题**，可展开查看合并内容。
3. 对方说完后点击 **确认回答**，合并上次确认后收到的所有对方语句，一起交给模型，并优先检索个人知识库。
4. 以本次提交为边界：生成回答期间录音继续，新语句留给下一轮；下一次确认只提交新的一批，不重复上一轮。

## 边界处理

- 已收到的最终转写都会收集，不用静音时长、问号或“像不像问题”来自动触发回答。
- 确认时若正在显示实时文字，等待当前语句定稿后提交；可以点击 **取消等待**。尚未被识别服务送达的语句到达后继续进入待确认区。
- 自己的麦克风转写不计入问题。单句「⚡答」、划选回答、自由提问和截图问答不会推进待确认问题。
- 回答中禁止重复提交本轮；停止或请求失败会把本轮语句放回待确认区，按原顺序与新语句一起重试。
- 待确认内容随会话保存。应用中断时未完成的一轮，下次打开会恢复为待确认；切换会话会取消尚在等待定稿的确认。
- 左侧「清空」会清除转录和待确认内容；右侧「清空」会停止尚在生成的回答，并把其问题放回待确认区。
- 显示气泡仍可因时间、长度等条件分开，但不影响本轮问题的完整归并。
