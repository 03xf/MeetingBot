# v0.2.0-beta.5 · 主动截断当前半句并回答

第一句已经显示、第二句还在说时，点击 **截到此刻并回答**，会把第一句和第二句已录到的部分一起识别后提交，不再等对方自然停顿。第二句尚未显示任何字幕时也适用。保留个人知识库优先作答、Markdown 排版和代码高亮。适用于 Windows 10 / 11 x64。

## 下载

- **安装版（推荐）**：`MeetingCopilot-0.2.0-beta.5-win-x64.exe`
- **免安装版**：`MeetingCopilot-0.2.0-beta.5-win-x64-portable.exe`
- 同名 `.sha256` 文件可校验下载完整性。

先完全退出旧版，再安装或启动新版，已有配置、知识库和历史记录会保留。

## 使用方法

1. 点击 **▶ 开始**，持续收取对方录音。
2. 根据需要点击 **截到此刻并回答**。应用主动结束当前录音段的识别，把上次提交后的语句与当前半句已录到的部分合并。
3. 界面显示正在整理问题，待识别服务返回最终文字后自动提交回答，并优先检索个人知识库。
4. 录音继续：截断后录到的内容进入下一轮。下一次点击只提交新的内容，不重复上一轮。

## 边界与异常

- 截断发生在音频处理线程收到请求时，接近点击时刻；存在系统调度延迟，不能保证精确到鼠标点击的某个采样点。尚未送满的 100ms 音频帧也会先送出，再设置分界。
- 不必等自然停顿，但仍需等待识别服务和回答模型响应，不能保证零延迟。切在词语中间、录音太短或声音不清楚时，转写准确性可能下降。
- 待确认句数与预览显示已定稿文字，正在说的半句会在截断识别完成后补入。
- 整理期间点击 **取消提交**，只取消本次自动回答；录音分界依然生效，已识别内容保留在待确认区。
- 识别超时、连接中断或服务重启时提示失败，本次不自动提交，已识别内容仍保留。失败前未能识别的音频不保证可恢复，请检查连接，必要时重新补充问题。
- 切换会话或清空转录会取消尚未提交的回答；清空后不会把旧截断结果重新补回来。
- 回答失败或停止生成会把本轮语句放回待确认区。自己的麦克风转写、单句「⚡答」、划选回答、自由提问和截图问答不推进本轮进度。
- 修复识别服务握手尚未完成就点击截断时的音频丢失，并保留不足正常分句长度的短尾音。整理期间停止录音也会继续完成截断后已缓冲音频的识别。
