# v0.2.0-beta.6 · 自定义提示词

在设置里增加一个纯文本的 **自定义提示词** 输入框，用于填写你自己的回答要求。保留主动截断并回答、个人知识库和代码框排版功能。适用于 Windows 10 / 11 x64。

## 下载与使用

- 安装版：`MeetingCopilot-0.2.0-beta.6-win-x64.exe`
- 免安装版：`MeetingCopilot-0.2.0-beta.6-win-x64-portable.exe`
- 同名 `.sha256` 文件用于校验下载完整性。

先完全退出旧版，再安装或启动新版，已有配置、知识库和历史记录会保留。

1. 打开 **⚙ 设置**，在 **AI 回答语言** 下方找到 **自定义提示词**。
2. 填写你的要求，例如：用自然口语详细回答；技术题先讲原理，再结合我的项目举例；代码默认使用 Java。
3. 点击设置底部的 **保存**，从下一次提问开始生效，无需重启。已经发出的回答不会重写。

## 生效范围

- 所有会话共用，重启后保留，可再次修改。清空并保存可恢复默认风格。
- 截断合并回答、单句回答、划选回答、自由提问、截图问答及多模态回答，都会在实际模型请求的系统消息中携带完整提示词。
- 填写时替代默认面试口述角色、固定回答长度和题型结构，避免与自定义要求冲突。未指定语言时默认使用设置中的回答语言。
- 知识库优先、个人事实不编造与代码块排版规则继续保留。专用翻译、连接测试、知识检索关键词提取和后台备忘摘要不套用回答风格。
- 提示词保存在本机，并随回答请求发送给你配置的模型；应用保证请求携带它，具体遵循程度仍取决于模型能力、服务商限制和提示词之间是否冲突。

## 验证

- 类型检查、419 项 TypeScript 测试、8 项 Python 测试和构建通过。
- 使用隔离配置和本地模拟模型，走实际界面编辑与保存、IPC、HTTP 请求，验证各回答路径均收到自定义提示词，含多模态路由。
- 验证修改后下一次请求立即更新、清空恢复默认、重新启动仍能读取并发送保存的提示词，翻译不受影响。
