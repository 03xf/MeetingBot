# v0.2.0-beta.8 · 背景透明度可调

MeetingBot 新增背景透明度滑块，可以透出后方桌面或窗口，同时保持文字和按钮清晰，代码框保留不透明底色。继续保留自定义提示词、知识库优先作答和主动截断并回答。

## 下载

- **安装版（推荐）**：`MeetingBot-0.2.0-beta.8-win-x64.exe`
- **免安装版**：`MeetingBot-0.2.0-beta.8-win-x64-portable.exe`
- 每个文件附同名 `.sha256` 校验文件，适用于 Windows 10 / 11 x64。

先完全退出旧版，再安装或启动新版。已有配置、知识库、历史记录和自定义提示词继续保留，数据仍使用 `%APPDATA%\MeetingCopilot`。

## 使用方法

1. 打开 **⚙ 设置**，在 **主题** 下方找到 **背景透明度**。
2. 拖动滑块即时预览：**0% 不透明，最高 95% 透明**。数值越大，背景越透明。
3. 点击设置底部 **保存**，当前窗口立即应用，重启后保留。取消或关闭设置会恢复原来的透明度。

深色、浅色和跟随系统主题均使用这项设置。滑块只改变主窗口底色，不设置整窗透明度，文字、按钮和代码不会随之变淡；代码框始终保留实底。设置面板、输入框、气泡等区域仍有各自的底色，配置向导保持独立的普通窗口。

新配置默认 20% 背景透明度。旧版已有的 opacity 配置会被沿用，可用新滑块调整。
