# v0.2.0-beta.9 · 无焦点交互测试版（Windows）

本版提供新的浏览 / 编辑模式，供下载后在自己的电脑上验证窗口焦点。**这是测试预发布版：尚未完成 Edge、Chrome 的真实鼠标和快捷键焦点验收，也未在飞书、北森平台实测。不能据此保证面试网站不提示切屏。**

## 下载与安装

- **安装版（推荐）**：`MeetingBot-0.2.0-beta.9-win-x64.exe`
- **免安装版**：`MeetingBot-0.2.0-beta.9-win-x64-portable.exe`
- 两个 EXE 均附同名 `.sha256` 文件；适用于 Windows 10 / 11 x64，未做代码签名。
- **离线自检页**：`MeetingBot-focus-check.html`，下载后分别用 Edge、Chrome 打开。

先完全退出旧版，再安装或启动新版。在设置中查看版本应为 `0.2.0-beta.9`。已有配置、知识库、历史记录和自定义提示词继续保留，数据仍使用 `%APPDATA%\MeetingCopilot`。

## 使用变化

- Windows 每次启动默认 **浏览模式**：主窗口不可聚焦，启动显示、快捷键唤醒、托盘显示和重复启动使用不激活的显示路径，不通过先抢焦点再恢复实现。
- 浏览模式保留点击回答、停止生成、滚动正文与代码、展开资料、切换会话和复制。会话菜单改为页面内菜单，复制通过主进程剪贴板接口完成。
- 需要输入问题、重命名、修改设置、选择音频设备或导入文件时，先进入 **编辑模式**。这些操作允许激活窗口；完成后点击标题栏的模式按钮返回浏览模式。隐藏后再次唤醒也恢复浏览模式，编辑状态不长期保存。
- 鼠标框选截图层在 Windows 上不可聚焦，以不激活的路径显示。框选完成提交截图问答；右键、取消按钮、再次按截图快捷键均取消，不全局拦截 Esc。过小选区、捕获失败和过期回调不会重复提交或叠加截图窗口。
- 保留主动截断录音、知识库、自定义提示词和背景透明度。标题栏“隐身”更名为 **采集保护**，明确其控制录屏采集，不能代表焦点或网站检测结果。

## 如何验证

1. 用 Edge 打开本版附带的离线自检页，点击开始测试，等待开始记录。保持浏览器为前台，MeetingBot 使用浏览模式。
2. 用真实鼠标和快捷键逐项测试：Ctrl+B 隐藏 / 唤醒、点击回答、滚动和复制、截图框选完成，以及右键 / 取消按钮 / 再按截图快捷键三种取消方式。每项可分别重置记录再测。
3. 查看是否新增失焦、隐藏或 `hasFocus()` 变为 false 的记录。出现任意一次即表示该操作未通过，请保留操作步骤和日志；不要只根据窗口还看得见判断。
4. 在 Chrome 重复测试。编辑模式本来就允许切换焦点，输入和选择文件应单独验证，之后返回浏览模式再测。
5. 离线页面通过只证明该测试条件下的浏览器事件表现。飞书、北森需在有权限的练习 / 测试页面分别验证；不要在正式面试中试验。Windows 前台窗口句柄与浏览器事件的联合验收仍待完成。
