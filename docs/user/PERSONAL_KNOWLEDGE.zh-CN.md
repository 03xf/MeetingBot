# 个人知识库

个人知识库跨会话共用，与每个会话的简历、岗位 JD 独立。手动回答、持续回答、自由提问、截图问答都会优先参考知识库；翻译保持忠实于输入，不注入个人资料。

## 使用

1. 在右侧回答区的顶部点击 **📚个人知识库**。
2. 点击 **导入文档**，可一次选中多份 Markdown、TXT、DOCX、文字版 PDF。
3. 在 **预览检索** 中输入实际问题，展开段落检查检索效果。预览完全在本机运行，不调用模型。
4. 正常提问。每条回答会显示本次提供给模型的参考段落，可以展开核对文件名和原文。
5. 同名同内容重复导入会去重；同名不同内容作为不同版本保留。移除过期版本可减少资料冲突。

扫描版 PDF 没有文字层，需要先做 OCR。单文件限制 20 MB、提取后 200 万字符，资料库总量限制 1000 万字符。导入失败会逐项提示，成功导入的文档会保留。

## 回答规则

- 资料相关且充分：依据知识库作答。
- 资料只覆盖一部分：先用资料回答，再补充通用知识。
- 本次未检索到相关段落：允许通用补充，但不能编造你的经历、项目、业绩和数字。
- 知识库、简历之间存在冲突：提示冲突，不自行猜测哪个版本正确。岗位 JD 不能当成个人经历。
- 知识库无法读取：显示错误，保护原文件，并要求模型说明无法核对资料。

这些规则通过提示词引导模型，并非事实正确性的硬性保证。显示的“参考资料”表示本次提供给模型的内容，不意味着模型一定采用了每一段，也不代表回答已经通过事实校验。

## 检索和延迟

本版使用本地中英文关键词检索（中文双字片段 + BM25 排序），不需要额外的向量数据库、模型下载或 Embedding API Key。小型资料库在预算内完整提供；大型资料库按问题选择最多 6 段、总计最多 6000 字符，避免将所有资料塞进每个请求。

关键词检索可能漏掉同义表达、跨语言表达和隐含关联。遇到未命中，请先用预览功能核对，补充术语、关键词或问题背景；不要把未命中理解为整个资料库没有答案。大量资料、同义表达丰富时，后续可再接入语义检索。

大型资料库的截图问答会额外调用一次已配置的视觉模型，从图片提取检索主题，再查找资料并生成回答，因此多一次请求的费用和延迟。小型资料库无需这一步。

## 数据和兼容

资料以明文保存在应用数据目录的 `knowledge.json` 中。文档解析、分段、检索在本机完成；回答时，选中的段落会发送给你配置的模型服务。旧版 `knowledge.md` 首次启动时自动迁移，原文件保留。

移除文档会影响后续检索；已经保存在会话中的回答和参考原文快照不会随之删除，需要另行清理对应会话。简历/JD 的导入和会话隔离方式保持不变。

知识库文件损坏时，应用仍可启动，但会停止对该文件的修改。可在知识库面板打开数据目录，备份并修复 `knowledge.json` 后重启。
